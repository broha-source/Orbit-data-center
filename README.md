# Orbit Data Center

Interactive research-demo website for **Orbital Data Center Flow**.

## Local preview

Open `index.html` directly, or serve this directory with any static web server.

## Publish with GitHub Pages

The included workflow publishes the repository root whenever `main` is updated. In the repository settings, select **GitHub Actions** as the Pages source.

## Before research publication

Replace the clearly marked concept values and overview copy with verified research content, figures, authors, affiliations, and links.
